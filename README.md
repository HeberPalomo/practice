## HOS Hours_left calculator
The program asks the driver, "How many hours have you driven?" The driver types a number, and it shows how many more hours they can drive.

### How to run
1. Install Python 3.
2. Open the terminal and go to the project folder.
3. Run:

```
python3 hos_hours_left.py
```

### Example

```
How many hours have you driven? 8
You can drive 3.00 more hours
That's 180 minutes
```
